# Patient photography

Drop licensed photographs for the postcard mockups here, then fill in the
matching slot in `src/content/photos.ts`.

Each photo of an identifiable person used in these slots needs **both** a
commercial-use licence **and** a signed model release — a stock licence alone
(Unsplash, Pexels and similar) grants the licence but explicitly not the
release. See the notes in `src/content/photos.ts`.

While a slot is empty the mockup falls back to its designed graphic treatment,
so the homepage is complete either way.

| Slot                 | Used on                                   | Crop       |
| -------------------- | ----------------------------------------- | ---------- |
| `newPatientPortrait` | "A Brighter Smile Starts Here." postcard  | ~3:4 portrait  |
| `communityLifestyle` | "Healthy Smiles, Happier Communities."    | ~3:2 landscape |

JPEG or WebP, at least 1200px on the long edge, sRGB.
